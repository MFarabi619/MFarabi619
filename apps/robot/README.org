** Getting Started

Install [[https://pixi.prefix.dev/latest/][Pixi]].

*** [[https://developer.nvidia.com/embedded/jetpack][NVIDIA Jetson Orin]] (JetPack 7.2.1, L4T R39.2.1, Ubuntu 24.04)

| Module         | Module ID  | Recovery USB ID | Boot storage        | Flash target                    | Hostname           |
|----------------+------------+-----------------+---------------------+---------------------------------+--------------------|
| Orin Nano 8 GB | P3767-0005 | =0955:7523=     | microSD 64 GB+      | =jetson-orin-nano-devkit=       | =jetson-orin-nano= |
| Orin NX 16 GB  | P3767-0000 | =0955:7323=     | NVMe M.2 2280 M-key | =jetson-orin-nano-devkit-super= | =jetson-orin-nx=   |

Both on the P3768 carrier. The bootloader is in module QSPI; only a recovery-mode
flash from x86_64 Linux writes it.

**** Flash from framework-desktop

Power off, seat the SD card or NVMe, jumper REC to GND on the button header,
USB-C to framework-desktop, power on. =lsusb= shows the Recovery USB ID.

#+BEGIN_SRC sh
mkdir -p ~/workspace/jetson-flash/{tmp,images}
curl -L -o ~/workspace/jetson-flash/Jetson_Linux_r39.2.1_aarch64.tbz2 \
    https://developer.nvidia.com/downloads/embedded/l4t/r39_release_v2.1/release/Jetson_Linux_r39.2.1_aarch64.tbz2
curl -L -o ~/workspace/jetson-flash/Tegra_Linux_Sample-Root-Filesystem_r39.2.1_aarch64.tbz2 \
    https://developer.nvidia.com/downloads/embedded/l4t/r39_release_v2.1/release/Tegra_Linux_Sample-Root-Filesystem_r39.2.1_aarch64.tbz2
#+END_SRC

#+BEGIN_SRC dockerfile ~/workspace/jetson-flash/Dockerfile
FROM ubuntu:22.04
ENV DEBIAN_FRONTEND=noninteractive
RUN apt-get update && apt-get install -y sudo bzip2 ca-certificates
COPY Jetson_Linux_r39.2.1_aarch64.tbz2 Tegra_Linux_Sample-Root-Filesystem_r39.2.1_aarch64.tbz2 /work/
WORKDIR /work
RUN tar xf Jetson_Linux_r39.2.1_aarch64.tbz2 \
 && tar xpf Tegra_Linux_Sample-Root-Filesystem_r39.2.1_aarch64.tbz2 -C Linux_for_Tegra/rootfs/
WORKDIR /work/Linux_for_Tegra
RUN ./tools/l4t_flash_prerequisites.sh
RUN mkdir -p rootfs/run/binfmt \
 && cp /usr/bin/qemu-aarch64-static rootfs/run/binfmt/aarch64-linux \
 && ./apply_binaries.sh \
 && rm -rf rootfs/run/binfmt
#+END_SRC

#+BEGIN_SRC sh
docker build -t jetson-flash ~/workspace/jetson-flash
#+END_SRC

Host temporaries, gone at reboot:

#+BEGIN_SRC sh
sudo modprobe nfsd
sudo mkdir -p /run/udev/rules.d
echo 'ACTION=="add", SUBSYSTEM=="net", ATTRS{idVendor}=="0955", ENV{NM_UNMANAGED}="1"' \
    | sudo tee /run/udev/rules.d/90-jetson-flash-nm-unmanaged.rules
sudo udevadm control --reload
sudo iptables  -I INPUT 1 -s 192.168.55.0/24 -m comment --comment jetson-flash -j ACCEPT
sudo ip6tables -I INPUT 1 -s fc00:1:1::/48  -m comment --comment jetson-flash -j ACCEPT
sudo ip6tables -I INPUT 1 -s fe80::/10      -m comment --comment jetson-flash -j ACCEPT
#+END_SRC

Flash target from the table; the SD card adds =--external-device mmcblk0p1=:

#+BEGIN_SRC sh
docker run -it --rm --name jetson-flash-run --privileged --network host -e USER=root \
    -v /dev/bus/usb:/dev/bus/usb -v /dev:/dev -v /run/rpcbind.sock:/run/rpcbind.sock \
    -v ~/workspace/jetson-flash/tmp:/work/Linux_for_Tegra/tools/kernel_flash/tmp \
    -v ~/workspace/jetson-flash/images:/work/Linux_for_Tegra/tools/kernel_flash/images \
    jetson-flash bash -c 'mkdir -p rootfs/run/binfmt \
      && cp /usr/bin/qemu-aarch64-static rootfs/run/binfmt/aarch64-linux \
      && exec ./tools/kernel_flash/l4t_initrd_flash.sh --erase-all jetson-orin-nano-devkit-super internal'
#+END_SRC

Success ends with =Flash is successful= / =Reboot device=. On failure, power cycle
with the jumper on and rerun.

| Symptom                                         | Cause                                 | Fix                             |
|-------------------------------------------------+---------------------------------------+---------------------------------|
| =chroot: failed to run command 'dpkg'= / exit 255 | NixOS binfmt wrapper execs =/nix/store= | emulator copy in the Dockerfile |
| =requires root privilege= as root                 | script checks =$USER=                   | =-e USER=root=                    |
| =Not starting NFS kernel daemon: no support=      | =nfsd= not loaded                       | =modprobe nfsd=                   |
| =does not support NFS export=                   | =exportfs= on an overlay path           | the two bind mounts             |
| =RPC: Timed out= after =Formatting APP partition=   | NetworkManager reset the USB link     | the udev rule                   |
| No display, no Linux, recovery works            | dead QSPI bootloader                  | this flash                      |

**** Wi-Fi

| Profile          | SSID             | Priority | Retries | Power save |
|------------------+------------------+----------+---------+------------|
| =openws-hotspot= | =openws-hotspot= |      100 |       0 | off        |
| =openws=         | =openws=         |       50 |       0 | off        |

The field hotspot wins whenever it is in range; =openws= is the fallback.

#+BEGIN_SRC sh
sudo nmcli connection add type wifi ifname wlP1p1s0 con-name openws-hotspot \
    ssid openws-hotspot wifi-sec.key-mgmt wpa-psk wifi-sec.psk '<password>' \
    connection.autoconnect-priority 100 connection.autoconnect-retries 0 \
    802-11-wireless.powersave disable
sudo nmcli connection modify openws \
    connection.autoconnect-priority 50 connection.autoconnect-retries 0 \
    802-11-wireless.powersave disable
#+END_SRC

The =rtl8822ce= driver manages its own regulatory domain and ignores =iw reg set=. With no
country code it finds no 5 GHz networks and joins 2.4 GHz.
Set the country on the driver and reboot:

#+BEGIN_SRC sh
echo 'options rtl8822ce rtw_country_code=CA' | sudo tee /etc/modprobe.d/rtl8822ce.conf
sudo reboot
#+END_SRC

Verify with =cat /sys/module/rtl8822ce/parameters/rtw_country_code= (prints =CA=) and
=nmcli dev wifi list --rescan yes= (lists 5 GHz networks).

**** Unlock MAXN_SUPER + grow swap

| Module         | nvpmodel conf                    | Ships as default | MAXN_SUPER mode | Boot default |
|----------------+----------------------------------+------------------+-----------------+--------------|
| Orin Nano 8 GB | =nvpmodel_p3767_0003_super.conf= | no, symlink it   | 2               |              |
| Orin NX 16 GB  | =nvpmodel_p3767_0000_super.conf= | yes              | 0               | 4 (40W)      |

Orin Nano:

#+BEGIN_SRC sh
sudo ln -sf /etc/nvpmodel/nvpmodel_p3767_0003_super.conf /etc/nvpmodel.conf
sudo nvpmodel -m 2
#+END_SRC

Orin NX:

#+BEGIN_SRC sh
sudo nvpmodel -m 0
#+END_SRC

Both:

#+BEGIN_SRC sh
sudo jetson_clocks   # optional, per-boot
#+END_SRC

#+BEGIN_SRC sh
swapon --show | grep -q /swapfile && sudo swapoff /swapfile
sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
grep -q /swapfile /etc/fstab || echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
#+END_SRC

*** Remote GPIO

**** [[https://www.beagleboard.org/boards/beagley-ai][BeagleY-AI]]

#+BEGIN_SRC sh
mkdir ~/workspace
git clone https://github.com/joan2937/lg ~/workspace/lg
cd ~/workspace/lg

make clean
make CPPFLAGS="-std=gnu17 -Wno-incompatible-pointer-types -Wno-implicit-function-declaration -Wno-int-conversion"
sudo make install
sudo /sbin/ldconfig
sudo env LD_LIBRARY_PATH=/usr/local/lib rgpiod -h
#+END_SRC

#+BEGIN_SRC sh
sudo tee /etc/systemd/system/rgpiod.service >/dev/null <<'EOF'
[Unit]
Description=lg remote GPIO daemon (rgpiod)
After=network.target

[Service]
Environment=LD_LIBRARY_PATH=/usr/local/lib
ExecStart=/usr/local/bin/rgpiod
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now rgpiod
systemctl status rgpiod --no-pager
sudo ss -ltnp | grep 8889
#+END_SRC

nc -vz beagleyai 8889
#+END_SRC
