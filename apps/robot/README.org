** Getting Started

Install [[https://pixi.prefix.dev/latest/][Pixi]].

*** Remote GPIO

**** [[https://www.beagleboard.org/boards/beagley-ai][BeagleY-AI]]

#+BEGIN_SRC sh
mkdir ~/workspace
git clone https://github.com/joan2937/lg ~/workspace/lg
cd ~/workspace/lg

make clean
make CPPFLAGS="-std=gnu17 -Wno-incompatible-pointer-types -Wno-implicit-function-declaration -Wno-int-conversion"
sudo make install
sudo /sbin/ldconfig
sudo env LD_LIBRARY_PATH=/usr/local/lib rgpiod -h
#+END_SRC

#+BEGIN_SRC sh
sudo tee /etc/systemd/system/rgpiod.service >/dev/null <<'EOF'
[Unit]
Description=lg remote GPIO daemon (rgpiod)
After=network.target

[Service]
Environment=LD_LIBRARY_PATH=/usr/local/lib
ExecStart=/usr/local/bin/rgpiod
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now rgpiod
systemctl status rgpiod --no-pager
sudo ss -ltnp | grep 8889
#+END_SRC

#+BEGIN_SRC sh
nc -vz beagleyai 8889
#+END_SRC

*** [[https://developer.nvidia.com/embedded/jetpack][NVIDIA Jetson Orin Nano]] (JetPack 7.2.1, L4T R39.2.1, Ubuntu 24.04)

**** Access

#+BEGIN_SRC sh
ssh-copy-id mfarabi@jetson-orin-nano.local
#+END_SRC

Passwordless sudo, so =deploy= runs unattended:

#+BEGIN_SRC sh
echo 'mfarabi ALL=(ALL) NOPASSWD:ALL' | sudo tee /etc/sudoers.d/010-mfarabi-nopasswd
sudo chmod 0440 /etc/sudoers.d/010-mfarabi-nopasswd
#+END_SRC

Serial device access — Ubuntu does not add users to =dialout= (Raspberry Pi
OS does), so without this the Roboteq driver crash-loops on =Permission denied=:

#+BEGIN_SRC sh
sudo usermod -aG dialout mfarabi
#+END_SRC

**** Verify JetPack + CUDA

#+BEGIN_SRC sh
head -1 /etc/nv_tegra_release
dpkg-query -W -f '${Status}\n' nvidia-jetpack   # want: install ok installed
test -x /usr/local/cuda/bin/nvcc && /usr/local/cuda/bin/nvcc --version
#+END_SRC

#+BEGIN_SRC sh
sudo apt install nvidia-jetpack   # if missing; CUDA 13.2 + cuDNN + TensorRT
#+END_SRC

**** Unlock MAXN_SUPER + grow swap

#+BEGIN_SRC sh
sudo ln -sf /etc/nvpmodel/nvpmodel_p3767_0003_super.conf /etc/nvpmodel.conf
sudo nvpmodel -m 2
sudo jetson_clocks   # optional, per-boot
#+END_SRC

#+BEGIN_SRC sh
sudo swapoff /swapfile
sudo fallocate -l 8G /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
#+END_SRC

    ipv4.method manual ipv4.addresses 192.168.1.11/24 ipv6.method disabled
